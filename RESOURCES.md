# Data Structures & Algorithms Interview Resources

## Knowledge

- [MIT OpenCourseWare: 6.006 Introduction to Algorithms](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/)
  Foundational algorithms course. Use for: asymptotic reasoning, core data structures, sorting/searching, graph traversal, and dynamic programming foundations.
- [Python Tutorial: Data Structures](https://docs.python.org/3/tutorial/datastructures.html)
  Official Python reference for lists, tuples, sets, dictionaries, loops, and common idioms. Use for: writing interview code in plain Python.
- [Python Library Reference: `collections`](https://docs.python.org/3/library/collections.html)
  Official reference for `deque`, `Counter`, and `defaultdict`. Use for: queues, frequency maps, graph adjacency lists, and counting problems.
- [CP-Algorithms](https://cp-algorithms.com/)
  Concise algorithm explanations with correctness ideas. Use selectively for: binary search, graph traversal, shortest paths, and dynamic programming recurrence design.
- [VisuAlgo](https://visualgo.net/en)
  Interactive algorithm visualizations. Use for: turning abstract pointer, heap, tree, and graph behavior into something visual.
- [LeetCode Explore](https://leetcode.com/explore/)
  Practice-oriented topic tracks. Use for: extra repetitions after a lesson has introduced a pattern.

## Wisdom (Communities)

- [LeetCode Discuss](https://leetcode.com/discuss/)
  Interview-prep community with solution discussions and company-tagged practice. Use for: comparing approaches after solving a problem yourself.
- [r/cscareerquestions](https://www.reddit.com/r/cscareerquestions/)
  Large software-career community. Use cautiously for: interview process anecdotes and preparation strategy, not for algorithm truth.
