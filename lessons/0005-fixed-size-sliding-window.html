Overview

A sliding window is a way to process a continuous part of a list or string. The window has a left edge and a right edge. As the algorithm runs, the window moves across the input while you keep useful information about what is inside it.

In this lesson, the window size is fixed: exactly k numbers. That makes the first version of sliding window easier to learn because every move does the same two actions: add one new value on the right and remove one old value on the left.

The Interview Move

Instead of recomputing each length-k subarray from scratch, keep a running window sum. Move one step right by adding the new right value and removing the old left value.

Sliding window is two pointers plus maintained state.

Core Ideas

Window

The current consecutive group of items being considered, such as [2, 1, 5].

State

The information you maintain about the window, such as its current sum.

Transition

The update when the window moves: add the entering value and remove the leaving value.

Best Answer

The best result seen so far, updated after each valid window.

Worked Example

Input: nums = [2, 1, 5, 1, 3], k = 3

The brute-force approach would sum [2, 1, 5], then separately sum [1, 5, 1], then separately sum [5, 1, 3]. That repeats work. Sliding window reuses the previous sum.

stepwindowupdatesumbest
Start[2, 1, 5]Initial sum88
Move 1[1, 5, 1]Add 1, remove 278
Move 2[5, 1, 3]Add 3, remove 199

The answer is 9, because the best length-3 subarray is [5, 1, 3].

Why This Is Faster

If you recompute every window from scratch, each window costs k additions. With many windows, that becomes O(nk). Sliding window keeps the old sum, so each move costs only two arithmetic operations: one add and one subtract. That makes the total time O(n).

Algorithm Steps

  1. Handle impossible input, such as k > len(nums).
  2. Build the first window using the first k values.
  3. Store that first window as the current best answer.
  4. Move the right edge from index k to the end.
  5. For each move, add the entering value and subtract the leaving value.
  6. Update the best answer after every complete window.

Python Template

def max_sum_size_k(nums, k):
    if k > len(nums):
        return None

    window = sum(nums[:k])
    best = window

    for right in range(k, len(nums)):
        window += nums[right]
        window -= nums[right - k]
        best = max(best, window)

    return best
