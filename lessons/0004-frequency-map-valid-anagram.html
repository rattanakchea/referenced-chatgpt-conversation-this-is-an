Lesson 4

Frequency Map for Valid Anagram

Goal: compare two strings by character counts.

Previous: Python Membership Roadmap Next: Sliding Window

The Interview Move

A set can tell you whether a value appeared. A dictionary can tell you how many times it appeared. For anagrams, order does not matter, but counts do.

Worked Example

"listen" and "silent" are anagrams because each character count matches.

Three Counting Strategies

StrategyCore ideaBest fit
Two mapsBuild one count map per input and compare them.Clearest general solution.
One balance mapIncrement for the first input and decrement for the second.Shows that every final balance must be zero.
Fixed arrayUse indices such as ord(ch) - ord("a").Only when the character set is explicitly small and fixed.

In an interview, state the input assumptions before choosing a fixed array. A dictionary handles Unicode and arbitrary hashable values without changing the algorithm.

Correctness and Complexity

Two strings are anagrams exactly when every character has equal multiplicity in both. The algorithm records those multiplicities, so equal maps are both necessary and sufficient. If the strings have different lengths, they cannot have equal total counts and you can return early.

Building the maps takes O(n) time. Space is O(k), where k is the number of distinct characters. Calling this O(1) space is only accurate when the alphabet is guaranteed to have a fixed maximum size.

Count, Consume, and Delete

Many frequency problems build an inventory and then consume it. Reject as soon as a requested value has no remaining count.

def can_construct(note, magazine):
    available = {}
    for ch in magazine:
        available[ch] = available.get(ch, 0) + 1

    for ch in note:
        if available.get(ch, 0) == 0:
            return False
        available[ch] -= 1

    return True

Deleting zero-count keys is optional for correctness here, but useful when map equality or the number of active keys matters.

Python Template

def build_counts(text):
    counts = {}

    for ch in text:
        counts[ch] = counts.get(ch, 0) + 1

    return counts

Coding Problem

Write is_anagram(a, b). Return True if both strings have exactly the same character counts.

assert is_anagram("listen", "silent") is True
assert is_anagram("rat", "car") is False
assert is_anagram("aabb", "baba") is True
assert is_anagram("aabb", "abb") is False
