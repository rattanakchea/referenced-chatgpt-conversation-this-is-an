Overview

Binary search works on sorted search spaces. Instead of checking every value, inspect the middle. If the middle is too small, everything to the left is also too small. If the middle is too large, everything to the right is also too large.

The Interview Move

Keep two boundaries: left and right. The answer, if it exists, must remain inside those boundaries. Every comparison tightens the range.

Binary search is not about finding the middle. It is about proving half the candidates are impossible.

The Search Invariant

At the start of every iteration, if the target exists, one occurrence lies in the inclusive range [left, right]. When nums[mid] < target, sorted order proves indices through mid are impossible, so the new left boundary is mid + 1. The symmetric argument moves right to mid - 1.

Every iteration removes at least mid, guaranteeing progress. Assigning left = mid or right = mid in this closed-interval template can create an infinite loop.

Exact Search vs. Boundary Search

GoalQuestion at midUseful final boundary
Exact matchIs this equal, too small, or too large?Return immediately on equality.
First value ≥ targetCould mid be the first valid index?left is the insertion position.
First true answerDoes candidate mid satisfy a monotonic condition?Smallest feasible candidate.
Duplicates make “find target” ambiguous. Ask whether any occurrence, the first occurrence, or the last occurrence is required.

Lower-Bound Template

This half-open range [left, right) finds the first index whose value is at least the target. It also gives the correct insertion position when the target is absent.

def lower_bound(nums, target):
    left = 0
    right = len(nums)

    while left < right:
        mid = (left + right) // 2
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid

    return left

Complexity and Edge Cases

Each comparison halves the candidate range, so time is O(log n) and iterative auxiliary space is O(1). Test an empty list, a one-item list, targets below and above the range, both endpoints, and duplicate values.

Python Template

def binary_search(nums, target):
    left = 0
    right = len(nums) - 1

    while left <= right:
        mid = (left + right) // 2

        if nums[mid] == target:
            return mid
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    return -1
