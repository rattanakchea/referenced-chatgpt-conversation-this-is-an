What a Heap Gives You

A heap keeps its smallest item at the front of a min-heap. Python's heapq module provides this operation in O(log n) time for each push or pop.

That makes a heap useful when you repeatedly need the next smallest or largest item, but do not need the whole collection sorted.

The Interview Move

For the kth largest value, keep a min-heap of at most k values. Every new value enters the heap. If the heap grows beyond k, remove its smallest value.

The heap's smallest item is the weakest member of the current top-k group. Removing it keeps the k strongest values, and the front is then the kth largest.

Worked Example

Find the 3rd largest value in [3, 2, 1, 5, 6, 4].

value enters heap after repair why
3, 2, 1 [1, 2, 3] Keep three values.
5 [2, 3, 5] Pop 1, the weakest top-3 candidate.
6 [3, 5, 6] Pop 2.
4 [4, 5, 6] Pop 3; front is 4.

Invariant

After processing each value, the heap contains exactly the largest min(k, values_seen) values encountered so far. Once at least k values have been seen, the smallest heap value is the kth largest seen value.

Python Template

import heapq

def kth_largest(nums, k):
    top_k = []

    for value in nums:
        heapq.heappush(top_k, value)
        if len(top_k) > k:
            heapq.heappop(top_k)

    return top_k[0]

Time is O(n log k) and extra space is O(k). Sorting would take O(n log n).

Retrieval Practice

  1. Why is the heap a min-heap when we want the kth largest?
  2. When do we pop from the heap?
  3. What does top_k[0] represent after repair?
  4. Why is the complexity O(n log k)?

Coding Problem

Write kth_largest(nums, k). Assume 1 <= k <= len(nums). 

assert kth_largest([3, 2, 1, 5, 6, 4], 2) == 5
assert kth_largest([3, 2, 3, 1, 2, 4, 5, 5, 6], 4) == 4
assert kth_largest([-1, -2, -3], 1) == -1

Common LeetCode Practice

  • Kth Largest Element in an Array — maintain a top-k min-heap.
  • Top K Frequent Elements — combine counting with a heap.
  • K Closest Points to Origin — keep the best k by distance.
  • Last Stone Weight — repeatedly remove the largest items.
