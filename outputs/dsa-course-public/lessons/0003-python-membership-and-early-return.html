The Interview Move

When you only need to know whether something appeared before, use a set. Ask if value in seen. If the answer means the problem is solved, return immediately. If the loop finishes, then no earlier return happened.

Membership Cost Matters

Containervalue in containerUse it when
listO(n)Order matters and membership checks are rare.
setExpected O(1)You need fast presence checks and unique values.
dictExpected O(1) for keysYou need presence plus associated data.

A loop that performs list membership on every iteration can become O(n²). Building a set costs O(n) space but usually reduces the full scan to O(n) time.

key in mapping checks dictionary keys, not values. Use key in mapping for fast lookup; searching mapping.values() is linear.

Early Return and Loop Meaning

The loop asks one question per element: “Have I already seen this?” A duplicate is decisive, so return True immediately. Returning False inside the loop would only prove that the first checked value was new—not that every value is unique.

# Wrong: stops after the first new value
for num in nums:
    if num in seen:
        return True
    return False

# Correct: False means the entire scan found no duplicate
for num in nums:
    if num in seen:
        return True
    seen.add(num)
return False

Python Details to Remember

  • An empty set is set(); {} creates an empty dictionary.
  • seen.add(value) changes the set in place and returns None.
  • Set elements and dictionary keys must be hashable, so lists cannot be inserted directly; tuples can.
  • discard safely ignores a missing value, while remove raises KeyError.

Python Template

def has_repeat(nums):
    seen = set()

    for num in nums:
        if num in seen:
            return True
        seen.add(num)

    return False
