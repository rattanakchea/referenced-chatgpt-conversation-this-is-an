Python Membership and Early Return

Goal: write the set-check loop correctly from memory.

The Interview Move

When you only need to know whether something appeared before, use a set. Ask if value in seen. If the answer means the problem is solved, return immediately. If the loop finishes, then no earlier return happened.

Worked Example

Input: [5, 1, 5]

valueseen before checkaction
5set()Not seen. Add 5.
1{5}Not seen. Add 1.
5{1, 5}Seen. Return True.

Python Template

def has_repeat(nums):
    seen = set()

    for num in nums:
        if num in seen:
            return True
        seen.add(num)

    return False

Coding Problem

Write first_repeated_value(nums). Return the first value that appears for a second time while scanning left to right. If there is no repeat, return None.

assert first_repeated_value([2, 5, 1, 2, 3, 5]) == 2
assert first_repeated_value([1, 2, 3]) is None
assert first_repeated_value([]) is None
assert first_repeated_value([7, 7, 8]) == 7
