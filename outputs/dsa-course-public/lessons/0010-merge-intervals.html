Overview

Interval problems are about ranges: meeting times, calendar blocks, network windows, or numeric spans. The usual first move is to sort by start time, then compare the current interval with the last interval already accepted.

The Interview Move

If the current start is less than or equal to the previous end, the intervals overlap. Merge them by extending the previous end to the larger end. Otherwise, start a new interval.

Sorting turns a messy overlap problem into a left-to-right scan.

Worked Example

Input: [[1, 3], [2, 6], [8, 10], [15, 18]]

currentlast mergedoverlap?result
[2, 6][1, 3]yes[1, 6]
[8, 10][1, 6]noappend [8, 10]
[15, 18][8, 10]noappend [15, 18]

The Merge Invariant

After processing the first i sorted intervals, merged contains their complete union as non-overlapping intervals. Because future starts cannot be earlier than the current start, only merged[-1] can overlap the next interval; all earlier merged intervals are permanently finished.

This is why sorting is the key transformation. Without it, a new interval might overlap any earlier range, forcing repeated searching or merging.

Boundary Semantics

The condition start <= last_end treats touching closed intervals such as [1, 4] and [4, 5] as overlapping. For half-open time ranges such as [start, end), where a meeting ending at 10 and another starting at 10 do not conflict, use start < last_end.

State what the endpoints mean before writing the overlap condition. One character—< versus <=—can change the answer.

Complexity, Mutation, and Edge Cases

Sorting dominates at O(n log n); the scan is O(n). The output can require O(n) space. This template mutates the input order and may reuse inner interval lists. If callers expect the original input unchanged, sort copied intervals instead:

ordered = sorted((start, end) for start, end in intervals)

Test empty input, one interval, nested ranges such as [[1, 10], [2, 3]], touching endpoints, identical intervals, and an interval that bridges several earlier ranges.

Python Template

def merge_intervals(intervals):
    if not intervals:
        return []

    intervals.sort(key=lambda pair: pair[0])
    merged = [intervals[0]]

    for start, end in intervals[1:]:
        last = merged[-1]
        if start <= last[1]:
            last[1] = max(last[1], end)
        else:
            merged.append([start, end])

    return merged
