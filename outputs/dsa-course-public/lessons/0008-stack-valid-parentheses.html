Overview

A stack is a last-in, first-out structure. The newest unresolved item is the first one you resolve. In Python interviews, a list usually acts as the stack: append pushes, and pop removes the most recent item.

The Interview Move

For valid parentheses, every closing bracket must match the most recent unmatched opening bracket. That is exactly stack behavior.

When you see nested structure, think stack.

The Stack Invariant

After reading any prefix of the string, the stack contains exactly the opening brackets that have not yet been matched, in encounter order. The top is the only opener the next closer may legally match. A mismatch or an empty stack proves the prefix can never be repaired by later characters.

The final empty-stack check handles the opposite failure: input such as "((" never sees an invalid closer, but still leaves unresolved openers.

Recognizing Stack Problems

  • Nested structure: brackets, tags, expression evaluation, directory paths.
  • Undo or cancellation: adjacent duplicates, backspaces, canonical paths.
  • Most recent unresolved item: matching events or decoding expressions.
  • Next greater or smaller item: use a monotonic stack of unresolved indices.
Store indices instead of values when the answer needs a distance, position, or later update.

From Regular to Monotonic Stack

In Daily Temperatures, the stack stores indices whose next warmer day is still unknown. When a warmer temperature arrives, it resolves every colder index on top. Each index is pushed once and popped at most once, so the full algorithm is O(n), even though a while loop appears inside the for loop.

def daily_temperatures(temperatures):
    answer = [0] * len(temperatures)
    stack = []  # unresolved indices, temperatures decreasing

    for i, temperature in enumerate(temperatures):
        while stack and temperatures[stack[-1]] < temperature:
            previous = stack.pop()
            answer[previous] = i - previous
        stack.append(i)

    return answer

Complexity and Pitfalls

Valid Parentheses takes O(n) time and up to O(n) space. Avoid pop(0), which removes from the front of a list and costs O(n); stack operations belong at the end.

  • Check not stack before calling pop().
  • Do not accept a matching prefix without checking that the stack ends empty.
  • If input may contain non-bracket characters, define whether to ignore or reject them.

Python Template

def is_valid_parentheses(s):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []

    for ch in s:
        if ch in "([{":
            stack.append(ch)
        else:
            if not stack or stack.pop() != pairs[ch]:
                return False

    return len(stack) == 0
