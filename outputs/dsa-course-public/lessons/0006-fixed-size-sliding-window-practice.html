Lesson 6

Fixed-Size Sliding Window Practice

Goal: recognize and code problems where every valid window has exactly k items.

Previous: Sliding Window Roadmap Next: Variable Window

Overview

A fixed-size sliding window is the right tool when the problem says exactly k consecutive items. The window length never changes. Only the position changes.

The repeated move is simple: add the new item entering from the right, remove the old item leaving from the left, then update the answer.

Core Template

def fixed_window(nums, k):
    if k > len(nums):
        return None

    state = build_state(nums[:k])
    answer = state

    for right in range(k, len(nums)):
        add nums[right] to state
        remove nums[right - k] from state
        update answer from state

    return answer

The line right - k is the index leaving the window. This is the most common place to make an off-by-one error.

Example 1: Maximum Sum of Size K

Easy

Problem

Return the maximum sum of any exactly length-k subarray.

assert max_sum_size_k([2, 1, 5, 1, 3], 3) == 9
assert max_sum_size_k([1, 2], 3) is None

Solution

def max_sum_size_k(nums, k):
    if k > len(nums):
        return None

    window = sum(nums[:k])
    best = window

    for right in range(k, len(nums)):
        window += nums[right]
        window -= nums[right - k]
        best = max(best, window)

    return best

Example 2: Maximum Average of Size K

Easy

Problem

Return the largest average of any exactly length-k subarray.

assert max_average_size_k([1, 12, -5, -6, 50, 3], 4) == 12.75
assert max_average_size_k([5], 2) is None

Key Idea

Track the best sum, then divide by k once. Avoid recomputing each average from scratch.

def max_average_size_k(nums, k):
    if k > len(nums):
        return None

    window = sum(nums[:k])
    best = window

    for right in range(k, len(nums)):
        window += nums[right]
        window -= nums[right - k]
        best = max(best, window)

    return best / k

Example 3: Count Windows Above a Threshold

Easy-Medium

Problem

Return how many length-k subarrays have an average greater than or equal to threshold.

assert count_windows_at_least([2, 2, 2, 2, 5, 5, 5, 8], 3, 4) == 3
assert count_windows_at_least([1, 1, 1], 2, 2) == 0

Key Idea

Compare sums instead of averages: average >= threshold means sum >= threshold * k.

def count_windows_at_least(nums, k, threshold):
    if k > len(nums):
        return 0

    need = threshold * k
    window = sum(nums[:k])
    count = 1 if window >= need else 0

    for right in range(k, len(nums)):
        window += nums[right]
        window -= nums[right - k]
        if window >= need:
            count += 1

    return count

Example 4: Contains Nearby Duplicate

Medium Bridge

Problem

Return True if the same value appears twice within distance k of each other.

assert contains_nearby_duplicate([1, 2, 3, 1], 3) is True
assert contains_nearby_duplicate([1, 2, 3, 1], 2) is False
assert contains_nearby_duplicate([1, 0, 1, 1], 1) is True

Key Idea

The window stores the previous at-most-k values. Before adding the current value, ask whether it is already inside that window.

def contains_nearby_duplicate(nums, k):
    window = set()

    for right, value in enumerate(nums):
        if value in window:
            return True

        window.add(value)

        if len(window) > k:
            window.remove(nums[right - k])

    return False
