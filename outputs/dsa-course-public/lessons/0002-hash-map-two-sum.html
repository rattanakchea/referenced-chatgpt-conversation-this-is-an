Hash Map Two Sum

Goal: solve Two Sum when the input is not sorted.

Previous: Two Pointers Roadmap Next: Python Membership

The Interview Move

For each number, compute the value that would complete the target. That value is the complement. If the complement has already appeared, return the two indices. If not, remember the current number for later.

Two pointers use sorted order to discard choices. Hash maps use memory to avoid re-scanning earlier choices.

Python Template

def two_sum(nums, target):
    seen = {}

    for i, value in enumerate(nums):
        need = target - value
        if need in seen:
            return [seen[need], i]
        seen[value] = i

    return [-1, -1]

Retrieval Practice

Answer from memory:

  1. What does seen store: needed values or previous values?
  2. Why should the code check need in seen before storing the current value?
  3. Compared with two pointers, what extra cost does this approach pay?

Coding Problem

Write contains_duplicate(nums). Return True if any value appears at least twice; otherwise return False. This is the same memory pattern, but simpler: instead of asking for a complement, ask whether the current value has already appeared.

assert contains_duplicate([1, 2, 3, 1]) is True
assert contains_duplicate([1, 2, 3, 4]) is False
assert contains_duplicate([]) is False
assert contains_duplicate([-1, -2, -1]) is True

Common LeetCode Practice

  • Two Sum — store previous values and search for complements.
  • Contains Duplicate — set membership for repeated values.
  • Intersection of Two Arrays — use sets to compare membership.
  • Majority Element — count or reason about repeated values.
