The Interview Move

When a list is sorted, the smallest useful value is on the left and the largest useful value is on the right. Add them. If the sum is too small, move the left pointer right. If the sum is too large, move the right pointer left.

The important idea is not the two variables. It is the reason movement is safe: sorted order proves that one side can no longer help.

Python Template

def has_pair_with_sum(nums, target):
    left = 0
    right = len(nums) - 1

    while left < right:
        total = nums[left] + nums[right]
        if total == target:
            return True
        if total < target:
            left += 1
        else:
            right -= 1

    return False

Move the pointer at the shorter line. Moving the taller line cannot improve the height limit, and it always makes width smaller.

def max_area(height):
    left = 0
    right = len(height) - 1
    best = 0

    while left < right:
        width = right - left
        area = min(height[left], height[right]) * width
        best = max(best, area)

        if height[left] < height[right]:
            left += 1
        else:
            right -= 1

    return best

Fixed value -4. Now search for two values that sum to 4.

def three_sum(nums):
    nums.sort()
    result = []

    for i in range(len(nums) - 2):
        if i > 0 and nums[i] == nums[i - 1]:
            continue

        left = i + 1
        right = len(nums) - 1

        while left < right:
            total = nums[i] + nums[left] + nums[right]

            if total == 0:
                result.append([nums[i], nums[left], nums[right]])
                left += 1
                right -= 1

                while left < right and nums[left] == nums[left - 1]:
                    left += 1
                while left < right and nums[right] == nums[right + 1]:
                    right -= 1
            elif total < 0:
                left += 1
            else:
                right -= 1

    return result

def move_zeroes(nums):
    write = 0

    for fast in range(len(nums)):
        if nums[fast] != 0:
            nums[write], nums[fast] = nums[fast], nums[write]
            write += 1

    return nums
