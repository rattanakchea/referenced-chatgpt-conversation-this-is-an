Loops

for x in nums:
    print(x)

for i, x in enumerate(nums):
    print(i, x)

for i in range(len(nums)):
    print(i, nums[i])

for i in range(len(nums) - 1, -1, -1):
    print(i, nums[i])

Set: Membership

seen = set()

for x in nums:
    if x in seen:
        return True
    seen.add(x)

return False

Use a set when the only question is whether a value appeared before.

Dictionary: Index Lookup

index_by_value = {}

for i, x in enumerate(nums):
    need = target - x
    if need in index_by_value:
        return [index_by_value[need], i]
    index_by_value[x] = i

return [-1, -1]

Use a dictionary when you need to map a value to information, such as an index or count.

Dictionary: Counting

count = {}

for x in nums:
    count[x] = count.get(x, 0) + 1

count.get(x, 0) means: if x already exists, use its count; otherwise use 0.

Counter

from collections import Counter

count = Counter(nums)

if count[x] > 0:
    print("available")

Counter is useful when the problem is mostly about frequencies. Manual dictionaries are still worth practicing because they reveal the update logic.

Defaultdict

from collections import defaultdict

graph = defaultdict(list)

for a, b in edges:
    graph[a].append(b)
    graph[b].append(a)

defaultdict(list) is common for graph adjacency lists and grouping values.

Deque: Queue

from collections import deque

q = deque([start])
seen = {start}

while q:
    node = q.popleft()
    for nei in graph[node]:
        if nei not in seen:
            seen.add(nei)
            q.append(nei)

Use deque for BFS because removing from the left is efficient.

Stack

stack = []

for x in values:
    stack.append(x)

while stack:
    top = stack.pop()

A Python list is the usual interview stack.

Heap

from heapq import heappush, heappop

heap = []
heappush(heap, 5)
heappush(heap, 2)
smallest = heappop(heap)  # 2

Python heaps are min-heaps. For max-heap behavior, push negative numbers.

heappush(heap, -score)
largest = -heappop(heap)

Binary Search Helpers

from bisect import bisect_left, bisect_right

i = bisect_left(nums, target)   # first position where target can go
j = bisect_right(nums, target)  # position after the last target

Use these when the problem is about insertion positions or count of values in a sorted list.

Sorting

nums.sort()

pairs.sort(key=lambda pair: pair[0])

words.sort(key=len)

descending = sorted(nums, reverse=True)

sort changes the list. sorted returns a new list.

Strings

s = "abc"

s[0]        # "a"
s[::-1]     # reversed string
"".join(chars)
s.lower()
ch.isalnum()

Strings are immutable. Build many characters with a list, then join once.

List Slicing

nums[:k]     # first k items
nums[k:]     # from k to end
nums[i:j]    # i through j - 1
nums[::-1]   # reversed copy

Slicing creates a new list or string, so it costs time and space proportional to the slice length.

Two Pointers

left = 0
right = len(nums) - 1

while left < right:
    total = nums[left] + nums[right]
    if total == target:
        return [left, right]
    if total < target:
        left += 1
    else:
        right -= 1

Sliding Window

window = sum(nums[:k])
best = window

for right in range(k, len(nums)):
    window += nums[right]
    window -= nums[right - k]
    best = max(best, window)
