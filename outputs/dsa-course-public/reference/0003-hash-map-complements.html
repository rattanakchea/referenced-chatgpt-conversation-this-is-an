Unsorted Two Sum

def two_sum(nums, target):
    seen = {}

    for i, value in enumerate(nums):
        need = target - value
        if need in seen:
            return [seen[need], i]
        seen[value] = i

    return [-1, -1]

Invariant

Before each iteration, seen maps values from earlier positions to one index where that value appeared. The current value only needs to check whether its complement already appeared.

Why Check Before Insert?

Checking before insertion prevents using the same index twice. For example, with nums = [4] and target = 8, inserting first would let the single 4 pair with itself.

Complexity

Time: O(n) average, because dictionary lookup is average constant time. Space: O(n), because the dictionary may store many previous values.
