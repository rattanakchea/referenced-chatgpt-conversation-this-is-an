Binary Search

Use binary search when one comparison can remove half the remaining search space.

Course home

Exact Search Template

def binary_search(nums, target):
    left = 0
    right = len(nums) - 1

    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    return -1

Invariant

If the target exists, it is always inside [left, right]. Each comparison proves one half cannot contain the answer.

Complexity

Time: O(log n). Space: O(1).
