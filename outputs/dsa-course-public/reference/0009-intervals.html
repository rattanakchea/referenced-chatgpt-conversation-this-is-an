Merge Intervals Template

def merge_intervals(intervals):
    if not intervals:
        return []

    intervals.sort(key=lambda pair: pair[0])
    merged = [intervals[0]]

    for start, end in intervals[1:]:
        last = merged[-1]
        if start <= last[1]:
            last[1] = max(last[1], end)
        else:
            merged.append([start, end])

    return merged

Core Question

Does the current interval start before or at the end of the previous merged interval? If yes, they overlap. If no, the current interval starts a new group.

Complexity

Time: O(n log n) because of sorting. Space: O(n) for the merged output.
