Phase 1: Linear Data Patterns

PatternCore questionTypical structures
Arrays and hashingHave I seen the value I need?dict, set, frequency maps
Two pointersCan sorted order or opposite movement remove choices?lists, strings
Sliding windowCan I maintain a valid range while expanding and shrinking?dict counts, two indices
StackDo I need the most recent unresolved item?list as stack

Phase 2: Ordered Search

PatternCore questionTypical structures
Binary searchCan one comparison remove half the search space?sorted lists, answer space
IntervalsHow do ranges overlap, merge, or exclude each other?sorted pairs
HeapDo I repeatedly need the next smallest or largest item?heapq

Phase 3: Recursive Structures

PatternCore questionTypical structures
TreesCan I solve left and right subproblems independently?DFS, BFS, recursion
GraphsWhat states are connected, and how do I avoid revisiting?adjacency lists, queue, stack
BacktrackingCan I build candidates incrementally and undo choices?recursion, path list

Phase 4: Dynamic Programming

Use DP only after the earlier patterns are stable. The key move is recognizing repeated subproblems and defining a state that is small enough to compute.
