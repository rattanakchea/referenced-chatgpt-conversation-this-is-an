Component Questions

Component Use it when... Tradeoff
CDN Content can be served near users. Cache invalidation and freshness.
Load balancer Multiple service instances should receive traffic. More moving parts and health behavior.
Cache Repeated reads justify a faster copy. Stale data and eviction policy.
Queue Work can happen later or needs smoothing. Eventually consistent completion and retries.
Object storage Files are large and addressed by key. Separate metadata and access control.

One Rule

Start with the smallest architecture that can satisfy the stated requirements. Add a component only when you can name the pressure it relieves: latency, throughput, durability, isolation, or operational control.
