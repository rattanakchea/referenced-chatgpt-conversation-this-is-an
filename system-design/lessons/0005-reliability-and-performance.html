Patterns That Work Together

Pattern Purpose Important caution
Timeout Prevent one dependency from holding resources forever. A timeout is not a fix for overload.
Retry Recover from transient failure. Backoff and jitter; retries can amplify load.
Idempotency key Make repeated writes safe. Store the result or deduplication record.
Rate limit Protect capacity and enforce fairness. Choose what happens to rejected requests.
Backpressure Slow producers when consumers cannot keep up. Make queue growth and user impact visible.
Observability See latency, errors, saturation, and traces. Signals need actionable ownership.

Performance Is a Budget

For a request with several sequential dependencies, their latency contributes to the response time. Parallel work can reduce wall-clock time but increases coordination. Caching can lower repeated reads but makes freshness a product decision. Async work can improve user latency but changes when completion becomes visible.

Always ask: what is the user waiting for, what can happen later, and what must be durable before we respond?
