Data and Storage Tradeoffs

Choose storage from access patterns, correctness, and scale.

Decision Prompts

  • What are the hottest keys and queries?
  • Which writes must be atomic together?
  • What relationships or joins matter?
  • Can a reader tolerate stale data?
  • How large is each record, and how fast does data grow?
  • What must happen if a write is repeated?

Common Moves

Move Benefit Cost
Index Faster known lookup. Write and storage overhead.
Replica Read capacity and availability. Replication lag and coordination.
Partition Spread data and load. Cross-partition work is harder.
Cache Lower repeated-read latency. Invalidation and memory limits.
Async event Decouple follow-up work. Delayed completion and delivery concerns.
