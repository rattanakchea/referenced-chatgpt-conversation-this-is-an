Architecture Building Blocks

Use a component when it solves a stated pressure.

Module homeRoadmapGuided practice
Block Primary job Watch for
DNS Map names to destinations. Routing, caching, failover.
CDN Serve cacheable content near users. Freshness and invalidation.
Load balancer Distribute requests across healthy instances. Health checks and session state.
Stateless service Validate requests and run business logic. Keep durable state elsewhere.
Cache Reduce repeated read latency/load. Eviction and staleness.
Database Store durable structured state. Access patterns and contention.
Queue Buffer and decouple asynchronous work. Retries, ordering, poison messages.
Worker Consume background work. Concurrency and idempotency.
Object storage Store large blobs by key. Metadata, permissions, lifecycle.
