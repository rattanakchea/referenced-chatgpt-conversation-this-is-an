# Mission: Data Structures & Algorithms Interview Readiness

## Why
Rattanak is building practical Data Structures & Algorithms coding skill to prepare for software engineering interviews at big tech companies. The goal is not trivia recall; it is to recognize common problem patterns, explain tradeoffs clearly, and implement correct Python solutions under interview constraints.

## Success looks like
- Solve easy interview problems reliably in Python while explaining the invariant and complexity.
- Progress into medium problems by recognizing patterns such as two pointers, sliding window, hash maps, stacks, binary search, BFS/DFS, heaps, and dynamic programming.
- Debug edge cases without guessing, using small test cases and clear reasoning.
- Build durable recall through short lessons, retrieval practice, and repeated coding feedback.

## Constraints
- Use Python for interview coding unless the workspace later indicates otherwise.
- Prefer concise lessons with one concrete win per session.
- Increase difficulty gradually from easy to medium.
- Prioritize patterns commonly seen in big-tech software engineering interviews.

## Out of scope
- Competitive programming tricks that rarely appear in mainstream interviews.
- Advanced graph algorithms, segment trees, tries, and hard dynamic programming until the easy/medium core is stable.
