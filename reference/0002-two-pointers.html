Two Pointers

Use two indices when movement rules let one step discard many impossible candidates.

Pattern Shapes

ShapeUse whenPointer rule
Opposite endsSorted order or width tradeoff lets you discard one side.Move the side that can no longer produce a better answer.

Sorted Pair Sum

def has_pair_with_sum(nums, target):
    left = 0
    right = len(nums) - 1

    while left < right:
        total = nums[left] + nums[right]
        if total == target:
            return True
        if total < target:
            left += 1
        else:
            right -= 1

    return False

Container With Most Water

def max_area(height):
    left = 0
    right = len(height) - 1
    best = 0

    while left < right:
        best = max(best, min(height[left], height[right]) * (right - left))
        if height[left] < height[right]:
            left += 1
        else:
            right -= 1

    return best

Move the shorter side because the shorter height limits the area.

3Sum

def three_sum(nums):
    nums.sort()
    result = []

    for i in range(len(nums) - 2):
        if i > 0 and nums[i] == nums[i - 1]:
            continue

        left = i + 1
        right = len(nums) - 1

        while left < right:
            total = nums[i] + nums[left] + nums[right]
            if total == 0:
                result.append([nums[i], nums[left], nums[right]])
                left += 1
                right -= 1
                while left < right and nums[left] == nums[left - 1]:
                    left += 1
                while left < right and nums[right] == nums[right + 1]:
                    right -= 1
            elif total < 0:
                left += 1
            else:
                right -= 1

    return result

Sorting makes duplicate skipping and pair-sum movement possible.

Move Zeroes

def move_zeroes(nums):
    write = 0

    for fast in range(len(nums)):
        if nums[fast] != 0:
            nums[write], nums[fast] = nums[fast], nums[write]
            write += 1

    return nums

fast reads every value. write tracks where the next non-zero value belongs.

Invariant

At every step, all discarded pairs are impossible. If the sum is too small, pairing the left value with any smaller right value would also be too small, so left can move right. If the sum is too large, pairing the right value with any larger left value would also be too large, so right can move left.

Complexity

Time: O(n), because each pointer moves inward at most n times total. Space: O(1), because no extra data structure grows with input size.

When It Fits

  • The input is already sorted, or sorting is acceptable.
  • You can decide which pointer to move based on a comparison.
  • You are searching pairs, ranges, palindromes, or partitions.
  • You need in-place cleanup where one pointer scans and another writes.
