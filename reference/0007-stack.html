Stack

Use a stack when the most recent unresolved item must be handled first.

Python Operations

stack = []
stack.append(value)  # push
top = stack.pop()    # pop
last = stack[-1]     # peek, only if stack is non-empty

Valid Parentheses Template

def is_valid_parentheses(s):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []

    for ch in s:
        if ch in pairs.values():
            stack.append(ch)
        elif ch in pairs:
            if not stack or stack.pop() != pairs[ch]:
                return False

    return len(stack) == 0

Common Signals

  • Nested structures: parentheses, brackets, tags.
  • Undo-like behavior: the latest thing is resolved first.
  • Monotonic stack problems: keep candidates in increasing or decreasing order.
