Heaps

Keep the next smallest or largest item available in logarithmic time.

Top-K Template

import heapq

def kth_largest(nums, k):
    top_k = []
    for value in nums:
        heapq.heappush(top_k, value)
        if len(top_k) > k:
            heapq.heappop(top_k)
    return top_k[0]

Core Question

Do I repeatedly need the next smallest or largest item? If yes, a heap may avoid sorting the entire input.

Goal Common heap Keep
kth largest Min-heap At most k largest values.
kth smallest Max-heap via negation At most k smallest values.
Always process earliest item Min-heap Pending items ordered by priority.

Complexity

Each push or pop costs O(log k) when the heap is bounded by k. Processing n values costs O(n log k); the heap uses O(k) extra space.
